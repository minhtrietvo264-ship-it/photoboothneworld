Kiến trúc đề xuất

Frontend chụp, lọc và xuất PNG bằng Canvas trên thiết bị. Backend cung cấp danh mục khung; lưu và chia sẻ ảnh là tính năng tùy chọn, chỉ tải lên khi người dùng chủ động chọn.

Trình duyệt
Camera · Canvas · PNG→REST API /v1
Khung · phiên chia sẻ→Database + Object storage
Metadata · ảnh có thời hạn

Endpoints

Nhấn chạy thử để xem phản hồi từ API mẫu.

Quy ước trước khi triển khai

API trả JSON; lỗi theo cấu trúc { error: { code, message, requestId } }. Upload giới hạn 10 MB, kiểm tra định dạng thực tế; link chia sẻ dùng token ngẫu nhiên và tự hết hạn sau 24 giờ. Admin cần đăng nhập và phân quyền; giới hạn tần suất tạo phiên và upload. Các phần này là thiết kế, chưa được triển khai trong bản duyệt.
